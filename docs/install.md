# Adding these to a Framer project

1. In Framer, open **Assets > Code** and click **+** to create a new code file.
2. Name it to match the file here (for example `CountUp`).
3. Paste the contents of the file and save.
4. Components appear in the Assets panel; drag them onto the canvas.
5. Overrides: select a layer, open **Code Overrides** in the right panel, pick the file and the `with...` function.

| File | Type | Use it for |
| --- | --- | --- |
| `components/CountUp.tsx` | Component | Animated stats and metrics |
| `components/CopyEmail.tsx` | Component | Contact sections |
| `overrides/ScrollProgress.tsx` | Override | Reading progress bar |
| `overrides/HoverLift.tsx` | Override | Cards and project tiles |
